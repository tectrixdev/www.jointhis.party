If you're using an Aternos server,
you can also get a nice,
fancy .jointhis.party custom IP.
In this guide we'll help you configure
your custom "IP" for your Aternos-ran server.

As Aternos already uses their own SRV records
and dynamic IPs for their servers, this will be very easy.
So head over to our [subdomain tool](/tool) and fill in this information:

<Card icon={<Wrench />} href="/tool" title="Subdomain tool.">
  Go to our subdomain tool.
</Card>

## Configuration

| Identifier     | Value                                                            |
| -------------- | ---------------------------------------------------------------- |
| Subdomain name | Your server name will become -> [subdomain name].jointhis.party. |
| Record type    | CNAME                                                            |
| Value          | Old .aternos.me server IP.                                       |
| Port           | Leave this empty.                                                |
