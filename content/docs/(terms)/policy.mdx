## Data collected

We, as jointhis.party, collect the following data by default:

- Your IP (logging, does not get viewed or used, only the estimated location is
  saved)
- Your User agent (Analytics)
- Your referrer (For example: The user came from google.)
- Pages you access (Analytics, logging)

We, as jointhis.party, collect the following data when you log in:

- The IP of the nearest cloudflare server (Authentication DB, this is the
  cloudflare IP due to the server being proxied. Your real IP is not stored. )
- Your User agent (Authentication DB, is accessible by me.)
- Your discord user ID (Authentication DB, is accessible by me.)
- The records you create and their contents (moderation purposes)
- Your discord email (Authentication DB, is accessible by me.)
- If your discord email is verified (Authentication DB, is accessible by me.)
- Your discord profile picture (Authentication DB, is accessible by me.)
- Your discord username (Authentication DB, is accessible by me.)

What happens to your data:

Regular data:

| Data             | Access                            | Storage                  | Storage retention                      |
| ---------------- | --------------------------------- | ------------------------ | -------------------------------------- |
| Discord user ID  | jointhis.party Discord moderators | DNS records / Cloudflare | As long as the DNS records are active. |
| Your IP          | Cloudflare                        | Cloudflare               | 1 month                                |
| User agent       | Me, Vercel                        | Vercel                   | 1 month                                |
| Your referrer    | Me, Vercel                        | Vercel                   | 1 month                                |
| Pages you access | Me, Vercel                        | Vercel                   | 1 month                                |

Data collected after authenticating:

| Data                                     | Access                            | Storage                                             | Storage retention      |
| ---------------------------------------- | --------------------------------- | --------------------------------------------------- | ---------------------- |
| Discord user ID                          | Me                                | Authentication DB                                   | Until account deletion |
| Your activity on the tool                | jointhis.party Discord moderators | Discord webhook messages, DNS records / Cloudflare. | Forever                |
| Nearest cloudflare datacenter            | Me                                | Authentication DB                                   | 1 month                |
| User agent                               | Me, Vercel                        | Vercel, Authentication DB                           | Until account deletion |
| Your referrer                            | Me, Vercel                        | Vercel                                              | 1 month                |
| Pages you access                         | Me, Vercel                        | Vercel                                              | 1 month                |
| The email linked to your discord account | Me                                | Authentication DB                                   | Until account deletion |
| Wether your discord email is verified    | Me                                | Authentication DB                                   | Until account deletion |
| Your Discord display name                | Me                                | Authentication DB                                   | Until account deletion |

The authentication DB is self-hosted on a VPS in the United States. Only I can
access the database. You can always request your data by sending an email to
[data.jointhis@tectrix.dev](mailto:data.jointhis@tectrix.dev) requesting your data.

You also have the right to deletion, in order for that to happen you can either
make a ticket on the discord server or send an email to [data.jointhis@tectrix.dev](mailto:data.jointhis@tectrix.dev).

If you don't want any of this data to get collected, you can always make a ticket
in our discord support server to get the record manually made, or get your proxy
tunnel manually created. We'd love to offer this service to anyone who likes some
extra privacy.

We don't sell your data in any way. They are only used for analytics, logging
and moderation. We don't share this data with any advertising providers or
data brokers.

## Cookies

Note: cf_clearance is cross-site but only for .jointhis.party sites,
it is merely for remembering CAPTCHA status. You can consult [the Cloudflare
documentation](https://developers.cloudflare.com/cloudflare-challenges/challenge-types/challenge-pages/challenge-passage/#how-it-works) if you want to learn more.

We only make use of functional cookies, no cross-site, no tracking,
no advertising, no nonsense. For the functional cookies, this is what they are
and what they do:

Included by default:

| Cookie name                    | Function                    | Max age    |
| ------------------------------ | --------------------------- | ---------- |
| cf_clearance                   | Cache CAPTCHA passes        | 30 minutes |
| \_\_Host-authjs.csrf-token     | CSRF protection             | session    |
| \_\_Secure-authjs.callback-url | Authentication callback url | session    |

Included when authenticated:

| Cookie name                     | Function                   | Max age |
| ------------------------------- | -------------------------- | ------- |
| \_\_Secure-authjs.session-token | Store authentication token | session |

## Local storage

| Cookie name       | Function                              | Max age |
