## Data collected

We, as jointhis.party, collect the following data by default:

- Your IP (logging, does not get viewed or used, only the estimated location is
  saved)
- Your User agent (Analytics)
- Your referrer (For example: The user came from google.)
- Pages you access (Analytics, logging)

We, as jointhis.party, collect the following data when you log in:

- Your discord user ID
- The records you create and their contents (moderation purposes)
- Your discord email (unused, but we have access)
- Your discord username (unused, but we have access)

What happens to your data:

| Data                      | Access                            | Storage                                             | Storage retention                      |
| ------------------------- | --------------------------------- | --------------------------------------------------- | -------------------------------------- |
| User ID                   | jointhis.party Discord moderators | DNS records / Cloudflare                            | As long as the DNS records are active. |
| Your activity on the tool | jointhis.party Discord moderators | Discord webhook messages, DNS records / Cloudflare. | Forever                                |
| Your IP                   | Cloudflare                        | Cloudflare                                          | 1 month                                |
| User agent                | Me, Vercel                        | Vercel                                              | 1 month                                |
| Your referrer             | Me, Vercel                        | Vercel                                              | 1 month                                |
| Pages you access          | Me, Vercel                        | Vercel                                              | 1 month                                |

We don't sell your data in any way. They are only used for analytics, logging
and moderation. We don't share this data with any advertising providers or
data brokers.

## Cookies

Note: cf_clearance is cross-site but only for .jointhis.party sites,
it is merely for remembering CAPTCHA status. You can consult [the Cloudflare
documentation](https://developers.cloudflare.com/cloudflare-challenges/challenge-types/challenge-pages/challenge-passage/#how-it-works) if you want to learn more.

We only make use of functional cookies, no cross-site, no tracking,
no advertising, no nonsense. For the functional cookies, this is what they are
and what they do:

Included by default:

| Cookie name                    | Function                    | Max age    |
| ------------------------------ | --------------------------- | ---------- |
| cf_clearance                   | Cache CAPTCHA passes        | 30 minutes |
| \_\_Host-authjs.csrf-token     | CSRF protection             | session    |
| \_\_Secure-authjs.callback-url | Authentication callback url | session    |

Included when authenticated:

| Cookie name                     | Function                   | Max age |
| ------------------------------- | -------------------------- | ------- |
| \_\_Secure-authjs.session-token | Store authentication token | session |

## Local storage
