# [www.jointhis.party](https://www.jointhis.party/)

> [!NOTE]  
> 2.0 is officially out!, you can view it at: [www.jointhis.party](https://www.jointhis.party/)

Jointhis.party is a project aimed to continue a previous project but larger and
with a slightly different goal. The goal of this previous project was to provide
free subdomains for users that self-hosted a minecraft server with a certain
reverse-proxy provider.

This project aims to provide a free subdomain for everything,
and we also aim to provide guides for every skill level to learn
how to self host. This is to make it useful not only for advanced self-hosters,
but also for beginners that don't know how to self-host anything.

## Development / contributing

Contributions are welcome using MRs.
For editing the guides and documentation,
you can just simply use the button on the page you want to edit.

- [Prettier code formatter](https://prettier.io/)
- [https://github.com/rvben/rumdl](https://github.com/rvben/rumdl)
- A working installation of pnpm

### Running locally

clone the repository:

```bash
git clone https://gitlab.com/tectrixdev/www.jointhis.party.git
```

```bash
pnpm i
```

Running the development server:

```bash
pnpm dev
```

Building:

```bash
pnpm build
```
